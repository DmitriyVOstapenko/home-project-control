# Безопасный и воспроизводимый внешний поиск

## Минимизация данных

Перед поиском удалить сведения, которые не нужны для сопоставления: точный частный адрес, ФИО, телефоны, реквизиты доступа, серийные номера, конфигурационные секреты, фотографии с персональными данными. Обычно для поиска достаточно региона, типа объекта, результата работ, объёма, класса оборудования и существенных технических ограничений.

Точный адрес или уникальный идентификатор допускается использовать только когда без него нельзя проверить обязательный региональный факт и пользователь подтвердил такую необходимость. Секреты не передавать во внешний поиск никогда.

## Что фиксировать

Для каждого запуска сохранять:

- точные запросы;
- дату проверки и регион;
- прямые URL использованных источников;
- найденных кандидатов и критерии отбора;
- ограничения сопоставимости;
- результат: `complete`, `partial` либо `blocked`;
- подтверждение, что ненужные приватные данные удалены.

## Качество источников

Характеристики проверять по официальной документации производителя; юридические и нормативные положения — по официальному источнику; цены — у продавца или подрядчика с датой, валютой, налогом, доставкой и доступностью. Отзывы являются сигналом для проверки, а не доказательством качества.

Кандидат не становится рекомендованным подрядчиком только потому, что найден в поиске. Если сопоставимой цены нет без прямого запроса, сформировать единое техническое задание и явно оставить цену неизвестной.
