## Замечание

| Поле | Требование |
|---|---|
| Наблюдение | Только то, что установлено |
| Место | Однозначный локатор |
| Критерий | Документ, пункт или согласованное требование |
| Влияние | Без домысла о причине |
| Исправление | Требуемый результат, не навязанный способ |
| Повторная проверка | Метод и доказательство закрытия |

## Итог

Перечислить проверенное, непроверенное, скрытое без фиксации, документы к получению, открытые замечания и допустимый статус этапа. После принятия указать, какие `Asset`, связи и события жизненного цикла нужно обновить; не заменять фактическое состояние данными КП.
