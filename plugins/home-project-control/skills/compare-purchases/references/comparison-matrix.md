# Матрица сравнения закупки

| Поле | Содержание |
|---|---|
| Позиция | Точное наименование |
| Модель / артикул | Идентификатор производителя |
| Обязательные параметры | Подтверждённые требования проекта |
| Совпадение | Полное / условное / нет / неизвестно |
| Количество | В сопоставимых единицах |
| Цена товара | С валютой и датой |
| Дополнительные затраты | Доставка, монтаж, комплектующие и прочее |
| Полная цена | Формула и результат |
| Наличие и срок | Со ссылкой на источник |
| Гарантия | Кто предоставляет и на каких условиях |
| Совместимость | Подключения, размеры, питание, управление, монтаж |
| Эксплуатация | Подтверждённые расходники, сервис и энергозатраты |
| Продавец и происхождение | Канал поставки, документы, возврат и риски |
| Жизненный цикл | Полная стоимость только по согласованному периоду и сценарию |
| Источник | Прямая ссылка или документ проекта |
| Риски | Только выявленные различия и неизвестные данные |
| Статус релевантности | Кандидат / подтверждён пользователем / отклонён |

Не ранжировать варианты с неизвестными обязательными параметрами как равнозначные подтверждённым.
