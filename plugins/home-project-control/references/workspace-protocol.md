# Рабочая папка проекта

## Граница плагина и проекта

Репозиторий или установленная копия `home-project-control` содержит код и инструкции плагина. Пользовательский проект хранится в отдельной выбранной пользователем папке. Один установленный плагин может обслуживать несколько таких папок.

Не создавать пользовательский проект внутри исходников плагина и не считать клонированный репозиторий папкой физического объекта или оборудования.

## Обязательная входная проверка

До чтения проектных документов:

Перед запуском утилит найти доступный интерпретатор Python 3: `python3`, `python`, `py -3` либо абсолютный путь, предоставленный средой. Путь к скрипту всегда разрешать относительно установленного каталога соответствующего скилла, а не относительно пользовательского проекта. В примерах ниже `python` обозначает выбранный интерпретатор Python 3.

1. определить точный абсолютный путь текущей рабочей папки из контекста среды;
2. найти установленный скрипт `skills/manage-project-evidence/scripts/inspect_project.py`;
3. выполнить `python <абсолютный-путь-к-установленному-скрипту> <текущая-папка>`;
4. продолжать профильную работу только при `status: existing_project_ready` и `gate_passed: true`;
5. повторить проверку, если рабочая папка изменилась.

Проверка работает только на чтение. Она подтверждает карточку проекта, привязку пути, обязательные каталоги и базовый формат реестров. Она не подтверждает истинность содержания документов.

## Новый проект

Если проект не найден:

1. объяснить, что нужен отдельный каталог;
2. получить от пользователя точный путь и название;
3. показать предварительный план командой `init_project.py <путь> --name <название> --dry-run`;
4. выполнить создание без `--dry-run` только после явного согласия на показанный путь и состав;
5. повторить `inspect_project.py`.

Если структура неполна или имеет поддерживаемую старую версию, сначала показать план `repair_project.py <путь>`. Применять его с `--apply` только после явного согласия. Заменяемые служебные файлы резервируются; оригиналы проектных документов не меняются. Повреждённый непустой JSONL-журнал блокирует структурную миграцию: его историю нельзя автоматически заменить пустым файлом, восстановление требует отдельного действия и подтверждения.

## Диалог без форм

Задавать вопросы в чате небольшими смысловыми блоками. Для закрытого вопроса давать короткий нумерованный список; свободный текст оставлять для уникальных фактов. Ответ на вопрос не означает согласия на запись, оплату, заказ, публикацию или изменение внешнего состояния.
