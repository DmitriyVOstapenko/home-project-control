# Контроль дома

Плагин для ChatGPT и Codex, который помогает вести покупку, строительство и ремонт дома или квартиры как проверяемый проект.

Плагин умеет:

- проверять рабочую папку и создавать безопасную структуру проекта;
- собирать исходные данные через интерактивные формы;
- проверять коммерческие предложения, сметы и договоры;
- сравнивать закупки и подтверждённые альтернативы;
- контролировать выполненные работы, изменения, сроки и платежи;
- вести локальную базу документов и связывать выводы с источниками;
- формировать отчёт о ходе проекта и фактических расходах.

## Состав

- `plugins/home-project-control/.codex-plugin/plugin.json` — карточка плагина;
- `plugins/home-project-control/skills/` — 12 специализированных скиллов;
- `plugins/home-project-control/mcp/` — локальный модуль интерактивных форм и проверки папки проекта;
- `.agents/plugins/marketplace.json` — каталог для установки и тестирования;
- `INSTALL.md` — подробная инструкция и сценарий первой проверки.

## Установка

Пока репозиторий закрыт, установить плагин может владелец репозитория или приглашённый участник с доступом к исходникам.

Для обычных пользователей предназначен файл **«Установить Контроль дома.cmd»** из выпуска GitHub. После запуска файла Codex откроет карточку плагина и попросит подтвердить установку.

Для разработки репозиторий можно клонировать локально и подключить его как каталог плагинов. Подробности приведены в [INSTALL.md](INSTALL.md).

## Принципы работы с данными

- Документы проекта хранятся в папке, выбранной пользователем.
- Оригиналы документов не изменяются.
- Факты из документов отделяются от предположений, внешних ориентиров и неизвестных данных.
- Создание и восстановление структуры выполняются только после подтверждения пользователя.
- Плагин не содержит и не отправляет документы конкретного строительного проекта.

## Статус

Текущая версия предназначена для закрытого тестирования на Windows в ChatGPT/Codex. Облачные хранилища Google Drive и Яндекс Диск пока не подключены.
